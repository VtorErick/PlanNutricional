### Full description
Plan Nutricional lleva tu plan alimenticio semanal al celular con una experiencia nativa para Android e iPhone.

Funciones principales:
- Plan semanal por perfil
- Ajuste y regeneracion con IA usando el backend actual
- Seguimiento diario de comidas
- Lista de compras consolidada
- Resumen personal y exportacion a PDF
- Recomendaciones de suplementos

Pensada para trabajar con los mismos datos y reglas del proyecto web original, ahora en una app movil lista para distribucion por tienda.
